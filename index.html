PROJECT PREVIEW

Built for connection

Janah Tech Connect is an early prototype for a cross-platform communication service.

  • Unique in-app user IDs
  • Local profile and contact storage
  • Offline-capable app shell
  • Designed to grow toward Android and iPhone
Important: This prototype does not yet transmit calls or messages to another phone. Offline app access is not the same as offline phone-to-phone communication. Real messaging, voice calls, cross-device discovery, account security, and server connectivity still need to be developed and tested.
